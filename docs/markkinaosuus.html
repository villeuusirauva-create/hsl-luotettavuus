# Operaattori Osuus Jakauma
Laskentaperiaate: Markkinaosuus on laskettu voimassaolevien sopimusten kilpailuttamisvaiheen vuosihinnoista (51 sopimusta). Luvut kuvaavat sopimuskannan rakennetta kilpailutushetken hintatasossa – todelliset maksetut korvaukset ovat korkeampia johtuen indeksitarkistuksista, suoritemuutoksista sopimuskauden aikana sekä laatu- ja ympäristöbonuksista.
